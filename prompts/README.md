## 🗂 Структура репозиторію

### 🛠 Базові шаблони завдань (8 файлів)
1. `prompts/component_generation.md` — Створення UI-компонентів з нуля.
2. `prompts/custom_hooks.md` — 🆕 Створення перевикористовуваних кастомних React хуків.
3. `prompts/performance.md` — 🆕 Оптимізація перформансу, рендерів та Core Web Vitals.
4. `prompts/testing.md` — Автоматизація написання тестів (Vitest/Playwright).
5. `prompts/review.md` — Глибокий аудит коду перед пулл-реквестом.
6. `prompts/documentation.md` — Генерація JSDoc, README та Storybook.
7. `prompts/debugging.md` — Діагностика та усунення помилок у коді.
8. `prompts/refactoring.md` — Чистий код, SOLID та покращення перформансу.

### 📐 Специфічні Markdown+XML шаблони під моделі Claude (2 файли)

10. `prompts/claude_xml_state.md` — Шаблон для стейт-менеджменту (Zustand/Redux).

### 🤖 Кастомні команди Claude Code CLI (2 файли)

12. `.claude/commands/generate-docs.js` — CLI-команда для авто-документування.
