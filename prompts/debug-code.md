# Goal
Знайти баги у `app/src/money.ts`, пояснити root cause кожного,
та запропонувати мінімальний fix.

# Context
Файл експортує функції для роботи з грошима у цілих центах:
`formatCents`, `parseAmount`, `splitEvenly`, `applyDiscount`.

Відомий симптом: `splitEvenly(1000, 3)` повертає `[333, 333, 333]` (сума = 999, а не 1000).
Можуть бути й інші баги — перевір усі функції на граничні випадки.

# Reproduction
```ts
splitEvenly(1000, 3)
// Очікувано: масив з сумою === 1000
// Фактично: [333, 333, 333], сума === 999
```

# Constraints
- Мінімальні зміни — лише те, що виправляє баг (не більше ~5 рядків на fix).
- Не змінювати сигнатури функцій.
- Не додавати нових залежностей.

# Output Format
Для кожного знайденого бага:

```
## Bug <N>: <короткий заголовок>
Рядок: <номер>
Симптом: <що відбувається неправильно>
Root cause: <чому>
Fix:
\`\`\`ts
<мінімальний diff — тільки змінені рядки>
\`\`\`
```

Якщо багів не знайдено (окрім відомого) — напиши "Інших багів не виявлено".

# Acceptance Criteria
1. Кожен знайдений баг має reproduction case (вхід → очікуваний результат → фактичний).
2. Fix не змінює поведінку для валідних входів, що вже працюють коректно.
3. Існуючі тести (`npm test`) проходять після виправлення.

# Stop
Зупинись після виведення списку багів з фіксами. Не застосовуй зміни до файлу.
