# Goal
Провести рев’ю файлу `app/src/money.ts` — знайти баги, проблеми коректності
та запропонувати покращення.

# Context
Файл містить утиліти для роботи з грошима в цілих центах:
`formatCents`, `parseAmount`, `splitEvenly`, `applyDiscount`.

Відомо, що `splitEvenly` має ваду із залишком — це in-scope для рев’ю.

# Review Dimensions
1. **Correctness** — логічні помилки, втрата даних, некоректні граничні випадки.
2. **Robustness** — відсутня валідація вхідних даних (NaN, Infinity, від’ємний `n`).
3. **Clarity** — іменування, читабельність, зайва складність.

Не перевіряй: стиль форматування (є prettier), типізацію (є tsc), безпеку XSS/injection (це backend-утиліта).

# Constraints
- Не змінюй код — лише коментуй.
- Тримайся лише файлу `app/src/money.ts`.

# Output Format
Для кожного знахідку:

```
[HIGH | MEDIUM | LOW] <рядок>: <короткий опис>
Проблема: <що саме не так>
Рекомендація: <як виправити>
```

Спочатку HIGH, потім MEDIUM, потім LOW. Якщо проблем не знайдено — напиши "Проблем не виявлено".

# Stop
Зупинись після виведення списку знахідок.
