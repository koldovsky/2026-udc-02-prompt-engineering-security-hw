# Context layer (Task D)

- [x] ignore-файл `.aiignore` — патерни: `node_modules/`, `app/node_modules/`, `app/.next/`, `app/out/`, `dist/`, `build/`, `package-lock.json`, `pnpm-lock.yaml`, `yarn.lock`, `*.log`, `.env`, `.env.*`, `.DS_Store`, `nul`
- Чому саме цей шар: `app/node_modules/` та інші ігноровані патерни охоплюють 913 файлів (955 → 42), які при відсутності
  ignore-файлу потрапляють у контекст і займають 99.6% токенів — суцільний шум без
  жодної корисної інформації. Той самий файл прибирає `.env` і секрети з контексту.

### Патерни `.aiignore`

| Патерн                                               | Що прибирає                         |
|------------------------------------------------------|-------------------------------------|
| `node_modules/`, `app/node_modules/`                 | залежності (950+ файлів)            |
| `dist/`, `build/`, `app/.next/`, `app/out/`          | білди                               |

## Дія курації

- Задача: генерація тестів для `app/src/money.ts` з промпту `/add-tests`.
- Що зробив: замість `@repo` (весь репозиторій) передав вузький контекст
  `@app/src/money.ts` — рівно один файл, потрібний для задачі.

## Вимірювання

| Метрика                       | До                                     | Після (`.aiignore`)          | Після (`@file`)        |
|-------------------------------|----------------------------------------|------------------------------|------------------------|
| Контекст (токени) / `repomix` | 8 547 114 (955 файлів, з node_modules) | 35 660 (42 файли, без шуму)  | 864 (1 файл)           |
| Output токени за задачу (≈)   | ~600 (весь repo, зайвий шум)           | —                            | ~280 (сфокусовано)     |
| Ітерацій до результату        | 2–3                                    | —                            | 1                      |

Як міряв: `npx repomix` з двома конфігураціями:

```bash
# До — жодного ignore, вся repo з node_modules
npx repomix --no-default-patterns --no-gitignore --output /dev/null
# → 955 files, 8 547 114 tokens

# Після — з .aiignore, без node_modules
npx repomix --output /dev/null
# → 42 files, 35 660 tokens

# Після — вузький @file, лише money.ts
npx repomix --include "app/src/money.ts" --output /dev/null
# → 1 file, 864 tokens
```

## Висновок

`.aiignore` скоротив контекст у **240 разів** — з 8.5M до 35.7K токенів. Основний
виграш дає виключення `node_modules/`, білдів та lock-файлів (913 файлів по всіх патернах); бонус безпеки —
`.env` та секрети зникають з контексту автоматично, без додаткових зусиль (той
самий ефект, що і в Tasks B/C). Вузька курація `@app/src/money.ts` для задачі
`/add-tests` скорочує контекст іще в **41 раз** — до 864 токенів: модель бачить
лише цільовий файл, що усуває «галюцинації» на основі нерелевантного коду і
зменшує кількість ітерацій до правильного результату.
