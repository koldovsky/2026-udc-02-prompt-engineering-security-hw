## Висновок

Курація через `.cursorignore` дала відчутне зменшення контексту (~41%), тобто менше шуму
і швидший фокус на коді `app/`. Додатково це покращує безпеку: `.env` та подібні файли
не потрапляють у контекст за замовчуванням. Для точкових задач найкраще спрацювало
звуження до конкретного `@file` замість усього репозиторію.
