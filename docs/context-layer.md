# Context layer (Task D)

## Що покращив (шари)

- [x] **`app/AGENTS.md`** — додав app-локальний шар: стек (TS strict, Node 22,
      ESM, vitest), команди (`npm test` / `test:watch` / `typecheck`) і 3
      конвенції (integer cents; тести поруч із кодом з імпортом `./*.js`; не
      хендфіксити засіяний баг — гнати через промпт).
- [x] **ignore-файл** — у репо вже є `.cursorignore` (node_modules, dist/build,
      lockfiles, `.env`, logs). Додав **`.repomixignore`** з тими ж патернами,
      щоб курація була **інструмент-незалежна** (і Cursor, і `repomix`,
      і будь-хто бачать однаковий «чистий» контекст).
- Чому саме ці шари: `AGENTS.md` веде агента до **5 реальних файлів** замість
  здогадок; ignore-файл прибирає важкий шум (`node_modules`) **і секрети**
  (`.env`) з будь-якого контексту — пряма синергія з Task B/C.

## Дія курації

- Задача: Task A — додати edge-case тести для `app/src/money.ts`.
- Що зробив: замість «дати агенту весь `app/`» звузив контекст до **вузького
  `@file`** — лише `src/money.ts` + `src/money.test.ts` (єдині файли, потрібні
  для задачі).

## Вимірювання

Міряв через `npx repomix` (реальний підрахунок токенів пакета контексту).

### A. Ефект ignore-курації (на `app/`)

| Метрика | До (без ignore: `--no-gitignore --no-default-patterns`) | Після (ignore активний) |
|---|---|---|
| Файлів у контексті | **882** | **5** |
| Контекст (токени) / `repomix` | **8 498 763** | **1 574** |
| Контекст (символів) | 34 152 667 | 6 129 |
| Фейковий секрет `.env` у контексті? | **ТАК** (`DEMO_API_KEY` потрапив) | **НІ** (виключений) |

→ зменшення ≈ **8.5M → 1.6k токенів** (у ~**5 400×**), і `.env` зник із контексту.
Основний «вантаж» — `app/node_modules` (49 МБ).

### B. Ефект вузького `@file` (у вже чистому `app/`)

| Метрика | До (весь curated `app/`) | Після (`@file`: money.ts + money.test.ts) |
|---|---|---|
| Файлів | 5 | **2** |
| Контекст (токени) / `repomix` | 1 574 | **1 159** |

→ ще ~**26%** менше навіть на крихітному репо; на реальному репозиторії різниця
«весь репо vs `@file`» — на порядки.

Як міряв: `npx repomix app` (curated), `npx repomix app --no-gitignore
--no-default-patterns` (naive), `npx repomix app --include
"src/money.ts,src/money.test.ts"` (@file). Числа відтворювані.

## Висновок

Курація контексту дає і **вартість**, і **безпеку**: ignore-файл прибрав ~8.5M
токенів шуму (≈99.98%) і водночас **викинув `.env`-секрет** із контексту —
без жодного промпта. Вузький `@file` далі ріже зайве й тримає увагу моделі на
релевантному коді. Висновок: дешевший, чистіший і безпечніший контекст — це
конфігурація (AGENTS.md + ignore + `@file`), а не випадковість; той самий
ignore-файл, що економить токени, закриває й канал витоку секретів (Task B/C).
