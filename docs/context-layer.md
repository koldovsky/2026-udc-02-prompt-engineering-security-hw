# Context layer (Task D)

## Що покращив (один шар)

- [x] `app/AGENTS.md` — новий файл: стек (TS ESM, Vitest, `tsc --noEmit`),
      команди (`npm test`, `npm run typecheck`), 3 конвенції (integer cents
      only, throw замість NaN/silent-wrong, реюз констант замість magic
      numbers).
- Чому саме цей шар: `app/` — ціль cookbook-промптів (Task A), але не мав
  власного AGENTS.md — агент мусив би вгадувати команди/конвенції з коду.
  Кореневий `.cursorignore` уже покриває `node_modules`/build/`.env` (мін. 3
  патерни вже є), тож другий ignore-шар додавати не було сенсу — цінніше було
  додати layer з явними правилами саме для цієї теки.

## Дія курації

- Задача: «дай агенту контекст для роботи над `app/`».
- Що зробив: замість «прочитай весь репозиторій» дав агенту вузький скоуп —
  тільки `app/` (аналог `@app/` замість `@repo`). Виміряв різницю через
  `npx repomix` для всього репо vs тільки `app/`.

## Вимірювання

| Метрика | До (весь репо) | Після (тільки `app/`, з новим `AGENTS.md`) |
|---|---|---|
| Контекст (токени), `npx repomix` | 25 151 (37 файлів) | 3 179 (6 файлів) |
| Зменшення | — | **−87.4%** (−21 972 токени) |
| Токени лише за появу `app/AGENTS.md` (`app/`-скоуп до/після) | 2 890 (5 файлів) | 3 179 (6 файлів, +289) |

Як міряв: `npx repomix --style plain -o out.txt <path>` — брав `Total Tokens`
з `Pack Summary` для (a) кореня репо, (b) теки `app/` до додавання
`AGENTS.md`, (c) теки `app/` після.

Побічний ефект: `npx repomix` на корені репо сам позначив
`materials/sensitive-ticket.md` і `docs/sanitization-checklist.md` як
"suspicious" (secrets/PII patterns) і виключив їх з паку — той самий ignore-
принцип з Task B/C: чутливе не має потрапляти в контекст моделі за замовчуванням.

## Висновок

Звуження контексту з «весь репозиторій» до цільової теки `app/` дало **~87%**
зменшення токенів (25 151 → 3 179) і повністю прибрало нерелевантний шум
(`docs/`, `materials/`, `prompts/`, `.claude/`) з контексту для задачі, яка
стосується лише `app/`. Новий `app/AGENTS.md` додав лише +289 токенів, але
дає агенту точні команди й 3 конвенції замість того, щоб вгадувати їх із коду
— тобто дешевий шар з високим сигналом. `repomix` також самостійно
відфільтрував 2 файли з PII/secret-патернами під час пакування всього репо,
що підтверджує цінність ignore-шару для безпеки контексту, а не лише для
економії токенів.
