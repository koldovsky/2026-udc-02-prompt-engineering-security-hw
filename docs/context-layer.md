## Висновок

Ignore-файл скорочує контекст у ~4 820 разів: `node_modules` у tiny-проєкті важить
понад 8.4 M токенів, реальний вихідний код — лише 1.8 K. Додатково прибирається
`.env` і логи — це одночасно оптимізація токенів **і** захист від витоку чутливих
даних (синергія з Task B/C). Вузьке `@file` на конкретний файл дає ще ×5 економію
відносно очищеного `app/`: агент не «тягне» тести й конфіг тоді, коли задача стосується
лише одного модуля.
