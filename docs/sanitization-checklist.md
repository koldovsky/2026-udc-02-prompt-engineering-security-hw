# Чек-ліст санітизації даних для AI (команда: payments-core)

## 1. Класифікуй (світлофор)

- [ ] **🔴 Ніколи публічним:**
  - Секрети: API keys, токени, паролі, DB connection strings, private keys
  - PII: ім'я, email, телефон, дата народження, адреса, паспорт, ІПН/РНОКПП
  - Банківська таємниця: номер картки, CVV, IBAN, баланс, виписки
  - Production-дані: дампи БД, реальні ID транзакцій, internal IP-адреси
  - Медичні / держ. / регульовані дані (GDPR, PCI DSS, HIPAA)
- [ ] **🟡 Лише enterprise/no-train:**
  - Внутрішній код під NDA, бізнес-логіка, назви мікросервісів
  - Схеми БД, архітектурні діаграми
  - Тікети з контекстом (без PII/секретів)
  - Анонімізовані логи, назви гілок, компонентів
- [ ] **🟢 Можна публічним:**
  - Публічний/OSS-код, синтетичні дані
  - Загальні технічні питання без даних
  - Acceptance criteria без реальних значень
  - Stack traces без значень змінних
- [ ] Сумнів → вважати 🔴. Маскувати або не давати взагалі.

## 2. Очисти (техніка під категорію)

| Техніка | Коли застосувати | Приклад |
|---------|-----------------|---------|
| **Redaction** | Поле не потрібне для задачі | `[REDACTED]` |
| **Masking** | Модель потребує структуру/формат | `****-1234`, `<IBAN>`, `[CUSTOMER_1]` |
| **Synthetic** | Потрібні «справжні на вигляд» дані | Вигадані ім'я/картка/IBAN |
| **Out-of-band** | Секрети (ключі, паролі, tokens) | `<SECRET_OUT_OF_BAND>` — не в промпт, брати з vault |

**Конкретні правила маскування:**

- Картка: `****-1234` (останні 4 цифри), exp — `**/**`, CVV — out-of-band
- IBAN: `<IBAN>` або `UA90...789` (часткова маска)
- Ім'я фізичної особи: `[CUSTOMER_1]`, `[CUSTOMER_2]`, …
- Email: `[CUSTOMER_1_EMAIL]`
- Телефон: `[CUSTOMER_1_PHONE]`
- ДН, паспорт, ІПН: `[CUSTOMER_1_DOB]`, `<PASSPORT>`, `<TAX_ID>`
- DB credentials: `<SECRET_OUT_OF_BAND>`
- API key / token: `<SECRET_OUT_OF_BAND>`
- Internal IP: `<INTERNAL_IP>`
- Баланс (якщо не потрібен): `<BALANCE>`

## 3. Перевір перед відправкою

- [ ] Чи можна реідентифікувати людину з решти полів? (ім'я + ДН + місто + посада)
- [ ] Чи не несе чутливе вставлений URL / скріншот / лог?
- [ ] Чи збережена **задача** після санітизації — чи модель ще може зрозуміти баг?
- [ ] Чи відповідає інструмент/tier категорії даних?
- [ ] Секрети вже в vault/env? Якщо «світилися» → ротація негайно.

---

## 4. Інструмент під категорію

| Категорія | Дозволений інструмент / tier | Нотатки |
|---|---|---|
| 🟢 | Будь-який публічний AI (ChatGPT, Claude.ai, Copilot free) | Без даних — без ризику |
| 🟡 | **Claude for Work / Copilot Business** (no-train tier) | Дані не йдуть на тренування; data residency EU якщо потрібно |
| 🔴 | Не давати жодним моделям | Тільки локально / вручну / скриптом; секрети — виключно через vault |

**Вибір для 🟡 (внутрішні дані):** Claude for Work або GitHub Copilot Business.
Причина: обидва надають no-train гарантії (дані не використовуються для тренування),
підтримують enterprise data residency і audit log. Для EU-даних — увімкнути EU data residency.
